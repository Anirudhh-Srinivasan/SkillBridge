# SkillBridge

AI skill mapping portal connecting students, industry and faculty.

## Folder layout

- `/backend` — FastAPI backend
- `/frontend-student` — React Vite student frontend
- `/frontend-dashboards` — React Vite dashboards frontend

## Ports

- Backend: `8000`
- Student frontend: `5173`
- Dashboards frontend: `5174`
